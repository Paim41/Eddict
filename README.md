# Eddict — Edit Addict

A browser-based, local-first photo editor and native-resolution video frame capture tool. The working project is located at `C:\Users\fahim\Projects\Eddict`, outside OneDrive.

## Features

- Upload, drop or paste JPEG, PNG and WebP photos.
- Fabric.js image layers with drag, proportional resize, rotate, opacity, duplicate, flip, visibility, lock, rename and ordering.
- Free and ratio crop, canvas resizing, undo/redo, reset, and IndexedDB recovery of the last project.
- Eddict Crystal, Eddict Porcelain and Black Aesthetic using the exact requested values. Each filter instance is processed sequentially; repeated filters are real repeated passes. The Applied Filters list supports removal, reordering and clearing.
- Twelve manual adjustments using the same engine as the preset stages. Manual adjustments run after the filter stack.
- Full-resolution PNG, JPEG and WebP downloads; PNG/WebP support transparency. JPEG uses a white background.
- Local MP4/WebM/MOV preview where the browser supports the codec; timestamp seeking, approximate frame stepping, native-resolution capture, lossless PNG or high-quality JPEG download, and direct editor handoff.
- Falling Sakura behind the interface, capped at 200 petals, paused when the tab is hidden, disabled with reduced-motion preferences. Sakura is never included in exports.
- Desktop inspector and mobile bottom toolbar/panel.

## Stack and commands

React, TypeScript (strict), Vite, Fabric.js, Lucide React and plain CSS. No backend is required. Use Node.js 22 or newer.

```sh
npm install
npm run dev
npm run build
npm run preview
npm run lint
npm test
```

`lint` performs TypeScript checking. Browser tests use Playwright and installed Microsoft Edge; change the test config channel if using another supported browser. The test runner starts a development server when needed.

Optional video test fixture (requires FFmpeg):

```powershell
New-Item -ItemType Directory -Force .test-assets
ffmpeg -f lavfi -i "testsrc2=size=640x360:rate=30:duration=2" -c:v libx264 -pix_fmt yuv420p -y .test-assets/sample.mp4
npm test
```

## Structure

`src/App.tsx` contains the shell and shortcuts; `editor.ts` owns the canvas, adjustment pipeline, history and persistence; `Panels.tsx` contains editing panels and export; `VideoStudio.tsx` handles frame capture; `Sakura.tsx` owns the background lifecycle; `stickers.ts` is the supplied-asset manifest. `tests/` contains browser regression tests. `public/` holds static assets, and `dist/` is generated by the production build.

## Privacy and limitations

Photos, videos, edits and exports stay in the browser. No image or video content is transmitted to a service. IndexedDB saves the current project on this device and origin; local preview and hosted site storage are separate. Browser storage can be cleared or exhausted, so export important edits.

Photo uploads are optimised above 6000 px per side or 24 megapixels. Video captures use native decoded dimensions without resizing or enhancement; direct editor handoff retains those dimensions up to the 64-megapixel safety limit. Codec availability and exact seeking depend on the browser. Frame buttons seek by 1/30 second and do not claim a measured frame rate. Large CPU-based adjustment stacks can take longer on high-resolution images.

## Licensing
